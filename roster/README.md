# roster

Week-01 in-class lab: practice the submission flow by opening a PR that adds your own file to this folder.

## Steps

1. Fork this repository and clone your fork.
2. Create `roster/<student-id>.md`. The filename is your student id.

```markdown
# 23512345

- github: Q00
- name: Jaegyu Lee
```

3. The `github:` value must be the account opening the PR. The automated check compares them.
4. Commit, push, and open a PR to upstream. Title: `[roster] 23512345`

Once the check is green it gets merged during class. This file then becomes the source of truth for "who owns this student-id directory" in every weekly assignment check.
